خطوات سريعة قبل ما تبدأ:

  1. حسابك حاليًا بانتظار تفعيل مدير النظام — بعد التفعيل تقدر تعدّل بيانات قسمك.
  2. من القائمة الجانبية، اختر أي قسم لعرض بياناته.
  3. فوق كل جدول تقدر تبدّل بين "عرض الجدول" و"عرض رسومي".
  4. خانة البحث تفلتر الجدول المفتوح فورًا.
  5. لو عندك صلاحية تعديل بقسمك، بتشوف أزرار "+ إضافة"، "تعديل" و"حذف".
  6. زر "اعتماد" يظهر لمحللي البيانات لتأكيد صحة السجل.
